# 31.1 ReconcileSmoother Komponente

## Ziel

Neue MonoBehaviour-Komponente die einen visuellen Correction-Offset verwaltet. Wird in LateUpdate NACH dem Motor's `CustomInterpolationUpdate()` ausgefuehrt und addiert einen exponentiell abklingenden Offset auf die Transform-Position.

## Neue Datei

`Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/ReconcileSmoother.cs`

## Anforderungen

- `[DefaultExecutionOrder(100)]` — CharacterMotorSystem hat `-100`, muss DANACH laufen
- Serialized Fields:
  - `_snapThreshold` (float, default 2.0) — ab dieser Distanz: hard snap
  - `_correctionRate` (float, default 0.25) — Decay-Rate (25% pro Frame bei 60fps)
  - `_rotationCorrectionRate` (float, default 0.25)
  - `_minCorrectionThreshold` (float, default 0.001) — unter diesem Wert: Zero
- Public API:
  - `SetCorrectionOffset(Vector3 posError, float rotError)`
  - `ClearOffset()`
  - `float SnapThreshold { get; }` — fuer NetworkCharacterDriver
  - `Vector3 CurrentOffset { get; }` — fuer Debug
- LateUpdate:
  - Frame-rate-unabhaengiger Decay: `Mathf.Pow(1 - rate, deltaTime * 60)`
  - Position: `transform.position += _positionOffset`
  - Rotation: `transform.rotation *= Quaternion.Euler(0, _rotationOffset, 0)`
  - Micro-Jitter vermeiden: `sqrMagnitude < threshold² → Zero`
