# 31.1 ReconcileSmoother → NetworkTickSmoother Migration

## Ziel

Custom ReconcileSmoother durch FishNet's eingebauten NetworkTickSmoother ersetzen. FishNet's Smoother handhabt Tick-Interpolation UND Reconcile-Correction automatisch — kein custom Smoothing-Code noetig.

## Warum Migration

Der custom ReconcileSmoother hatte fundamentale Probleme:
- **Offset-Akkumulation:** Jede Reconcile-Korrektur addierte zum Offset → persistenter 1.5-3.5m visueller Versatz
- **Zwei Systeme kaempften:** KCC-Interpolation vs ReconcileSmoother auf demselben Transform
- **Unregelmaessiges Tick-Timing:** ParrelSync (0-Tick + Multi-Tick Frames) → Goal-Queue Drift
- **Kein RTT-Adaptation:** Feste Interpolation unabhaengig von Latenz

FishNet's NetworkTickSmoother loest alle diese Probleme:
- **Velocity-basiertes MoveTowards** statt Linear Lerp → gleichmaessige visuelle Geschwindigkeit
- **Reconcile-Easing ueber Replay-Buffer** (Power-Kurve in OnPostReplicateReplay) → kein Offset
- **Adaptive Interpolation** basierend auf RTT
- **Automatisches Buffer-Management** mit Speed-Anpassung (±5%)

## Geloeschte Datei

`Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/ReconcileSmoother.cs`

## Geaenderte Dateien

### NetworkCharacterDriver.cs — Vereinfacht

Entfernt:
- `ReconcileSmoother _smoother` Feld
- `_didReconcile`, `_preReconcilePosition`, `_preReconcileRotation` Felder
- Server-Side Guard (`_smoother = null`)
- `OnPreTick()` / `OnPostTick()` Aufrufe in TimeManager_OnTick/OnPostTick
- `OnReconcileComplete()` Aufruf in PerformReplicate
- Pre-Reconcile Position Saving in PerformReconcile

Beibehalten (KRITISCH):
- `CharacterMotorSystem.Settings.Interpolate = false` — KCC-Interpolation deaktiviert
- `_motor.Transform.SetPositionAndRotation(TransientPosition)` vor Simulate() — Motor startet immer von Sim-Position

### NetworkSetupWizard.cs — NetworkTickSmoother statt ReconcileSmoother

- ReconcileSmoother durch NetworkTickSmoother ersetzt
- TargetTransform = root (das Objekt das sich jeden Tick bewegt)
- Controller: AdaptiveInterpolation = Low, Teleport bei 5m
- Spectator: AdaptiveInterpolation = Moderate, Teleport bei 5m
- FavorPredictionNetworkTransform = false (wir nutzen kein NetworkTransform)

## FishNet NetworkTickSmoother Konfiguration

```
InitializationSettings:
  TargetTransform = this.transform (root = Motor + Visual)
  GraphicalTransform = this.transform (automatisch gesetzt)
  DetachOnStart = false
  FavorPredictionNetworkTransform = false

Controller (Owner) MovementSettings:
  AdaptiveInterpolation = Low (RTT + 3 Ticks)
  InterpolationValue = 2 (Fallback ohne Adaptive)
  EnableTeleport = true
  TeleportThreshold = 5m
  SmoothedProperties = Everything

Spectator MovementSettings:
  AdaptiveInterpolation = Moderate (RTT + 4 Ticks)
  EnableTeleport = true
  TeleportThreshold = 5m
```
