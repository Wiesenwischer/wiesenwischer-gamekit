# 31.4 Debug Visualization

## Ziel

Debugging-Tools fuer Reconcile-Smoothing: Gizmos, optionales Logging und NetworkDebugUI Erweiterung.

## Aenderungen

### ReconcileSmoother.cs

- `[Header("Debug")]`
- `[SerializeField] private bool _debugLog = false;` — loggt Corrections, Stutter-Detection, Status alle 120 Frames
- **Stutter-Detection**: Bewegungsdelta-Ratio > 5:1 oder < 1:5 → `LogWarning` mit delta, offset, queue, interpT
- **Periodic Status**: Position, from/to, interpT, queue-size, offset, fps alle 120 Frames
- `OnDrawGizmos()`: Gelbe Linie von `transform.position` zu `transform.position - _positionOffset`
  - Zeigt wohin korrigiert wurde
  - Nur wenn Offset > MinThreshold

### NetworkCharacterDriver.cs

- `[SerializeField] private bool _debugLog` — loggt OnTick/OnPostTick Positionen, Reconcile-Error, Server-Startup-Info
- Zeigt isDedicatedServer Status, Smoother-Verfuegbarkeit, Tick-Rate, KCC-Settings

### NetworkDebugUI.cs (optional)

Falls vorhanden, Correction-Offset Magnitude anzeigen:
- `ReconcileSmoother.CurrentOffset.magnitude` als zusaetzliche Zeile
