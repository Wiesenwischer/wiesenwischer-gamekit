# 31.3 Spectator Prediction Verbesserung

## Ziel

Spectator-Prediction verbessern: konfigurierbares Predict-Ahead (statt hardcoded 2 Ticks) und Correction-Offset bei Ankunft neuer autoritativer Daten.

## Aenderungen

**Datei:** `Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/NetworkCharacterDriver.cs`

### Konfigurierbares Predict-Ahead

```csharp
[SerializeField] private int _spectatorMaxPredictTicks = 4;
```

Ersetzt das hardcoded `> 2` in der Spectator-Sektion.

### Neue Felder

```csharp
private Vector3 _spectatorPreCorrectionPos;
private bool _spectatorNeedsCorrection;
```

### Spectator Correction Flow

Wenn fuer einen Spectator `state.ContainsTicked()` — neuer autoritativer Input:
1. Position VOR Anwendung speichern: `_spectatorPreCorrectionPos = _motor.TransientPosition`
2. `_spectatorNeedsCorrection = true`
3. Normaler Simulations-Lauf
4. NACH Simulation: Error berechnen = `_spectatorPreCorrectionPos - _motor.TransientPosition`
5. Offset setzen oder clearen (gleiche Threshold-Logik wie Owner)

### Hinweis

Spectator-Correction ist weniger kritisch als Owner-Correction, da Spectators keine eigene Prediction/Reconcile-Schleife haben. Die Korrektur hier faengt den Moment ab, wenn predicted Input durch echten Input ersetzt wird.
