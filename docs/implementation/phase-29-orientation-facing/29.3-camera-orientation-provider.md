## Ziel

Die **Bridge-Komponente** `CameraOrientationProvider` implementieren, die CameraBrain-State in `IOrientationProvider` und `IFacingProvider` Semantik übersetzt. Sitzt auf dem CameraBrain-GameObject und liest den aktuellen Orbit-State.

Zusätzlich **CameraBrain** um die benötigten öffentlichen Properties erweitern (`OrbitActivation`, `CurrentOrbitMode`, `FollowTarget`).

## Neue Dateien

### CameraOrientationProvider.cs

**Pfad:** `Packages/Wiesenwischer.GameKit.Camera.Core/Runtime/Core/CameraOrientationProvider.cs`

```csharp
using UnityEngine;
using Wiesenwischer.GameKit.CharacterController.Core;

namespace Wiesenwischer.GameKit.Camera
{
    /// <summary>
    /// Bridge zwischen Camera-System und Character-Controller.
    /// Übersetzt CameraBrain-State in IOrientationProvider/IFacingProvider Semantik.
    /// Sitzt auf dem CameraBrain-GameObject.
    /// </summary>
    [RequireComponent(typeof(CameraBrain))]
    public class CameraOrientationProvider : MonoBehaviour,
        IOrientationProvider, IFacingProvider
    {
        private CameraBrain _brain;

        private void Awake()
        {
            _brain = GetComponent<CameraBrain>();
        }

        // --- IOrientationProvider ---

        public Vector3 GetMovementForward()
        {
            bool useCameraFrame =
                _brain.OrbitActivation == OrbitActivation.AlwaysOn
                || _brain.CurrentOrbitMode == CameraOrbitMode.SteerOrbit;

            if (useCameraFrame)
            {
                // Camera Forward (Y=0, normalisiert)
                return _brain.Forward;
            }
            else
            {
                // Character Forward
                var target = _brain.FollowTarget;
                return target != null ? target.forward : Vector3.forward;
            }
        }

        public Vector3 GetMovementRight()
        {
            Vector3 forward = GetMovementForward();
            return Vector3.Cross(Vector3.up, forward).normalized;
        }

        // --- IFacingProvider ---

        public FacingMode GetFacingMode()
        {
            if (_brain.OrbitActivation == OrbitActivation.AlwaysOn)
                return FacingMode.MovementDirection;

            // ButtonActivated (ClassicMMO)
            return _brain.CurrentOrbitMode switch
            {
                CameraOrbitMode.SteerOrbit => FacingMode.CameraForward,
                _ => FacingMode.MovementDirection
            };
        }

        public Vector3 GetFacingDirection()
        {
            return _brain.Forward;
        }
    }
}
```

**Design-Entscheidung — Warum `UseCameraFrame`:**

| Preset | OrbitMode | Frame | Begründung |
|--------|-----------|-------|-----------|
| AlwaysOn | FreeOrbit (immer) | Camera | BDO/TERA: W = Kamerarichtung |
| ButtonActivated | None | Character | WoW ohne Button: W = Character-Vorwärts |
| ButtonActivated | FreeOrbit (LMB) | Character | WoW LMB: Kamera orbitet, aber W bleibt Character-Vorwärts |
| ButtonActivated | SteerOrbit (RMB) | Camera | WoW RMB: W = Kamerarichtung, Character folgt |

### CameraBrain.cs — Neue Properties

**Pfad:** `Packages/Wiesenwischer.GameKit.Camera.Core/Runtime/Brain/CameraBrain.cs`

Drei neue öffentliche Properties hinzufügen:

```csharp
/// <summary>Aktueller OrbitActivation-Modus aus dem Preset.</summary>
public OrbitActivation OrbitActivation => _inputPipeline != null
    ? _inputPipeline.OrbitActivationMode
    : OrbitActivation.AlwaysOn;

/// <summary>Aktueller OrbitMode aus dem letzten Input-Frame.</summary>
public CameraOrbitMode CurrentOrbitMode => _context?.Input.OrbitMode
    ?? CameraOrbitMode.FreeOrbit;

/// <summary>Das Follow-Target (Character Transform).</summary>
public Transform FollowTarget => _context?.FollowTarget;
```

**Hinweis:** `IsSteerMode` und `Forward` existieren bereits. Die neuen Properties sind rein additiv — kein bestehendes Verhalten ändert sich.
