# 29.4 CharacterController Integration

> **Commit:** `feat(phase-29): 29.4 CharacterController Orientation/Facing Integration`
> **Branch:** `feat/cc-orientation-integration` (vom Integration-Branch)

---

## Ziel

**PlayerController** und **CharacterLocomotion** auf die neuen Provider umstellen:

1. **PlayerController** resolves `IOrientationProvider` + `IFacingProvider` und füllt `LocomotionInput` mit den neuen Feldern
2. **CharacterLocomotion** nutzt `FacingMode` für die Rotationslogik statt `IsSteerMode`

Dies ist der **Kernschritt** der Phase — hier wird die bisherige direkte Camera-Abfrage durch das abstrakte Provider-System ersetzt.

## Bestehende Dateien modifizieren

### 1. PlayerController.cs

**Pfad:** `Packages/Wiesenwischer.GameKit.CharacterController.Core/Runtime/Core/PlayerController.cs`

#### Neue Felder

```csharp
private IOrientationProvider _orientationProvider;
private IFacingProvider _facingProvider;
```

#### Provider-Auflösung (in Start/Awake oder Lazy)

```csharp
private void ResolveProviders()
{
    // Orientation + Facing Provider vom CameraBrain-Hierarchy auflösen
    _orientationProvider = GetComponentInParent<IOrientationProvider>();
    _facingProvider = GetComponentInParent<IFacingProvider>();

    // Fallback: ICameraOrbitProvider bleibt für Legacy-Kompatibilität
    if (_orientationProvider == null)
    {
        ResolveOrbitProvider(); // Bestehende Methode
    }
}
```

**Hinweis:** `GetComponentInParent<IOrientationProvider>()` findet den `CameraOrientationProvider` auf dem CameraBrain-GameObject, das typischerweise ein Parent oder Sibling des Player-Prefabs ist. Falls die Hierarchie anders ist, muss `FindObjectOfType<>()` oder ein expliziter Serialized-Reference verwendet werden.

**Alternative (robuster):** Suche auf Root-Ebene:
```csharp
_orientationProvider = FindAnyObjectByType<CameraOrientationProvider>();
_facingProvider = _orientationProvider as IFacingProvider;
```

#### ApplyMovement() anpassen

**Vorher:**
```csharp
bool isSteerMode = _orbitProvider?.IsSteerMode ?? false;
Vector3 lookDir = isSteerMode ? GetCameraForward() : transform.forward;

var input = new LocomotionInput
{
    MoveDirection = moveInput,
    LookDirection = lookDir,
    // ...
};
```

**Nachher:**
```csharp
// Frame-Space: Worin wird WASD interpretiert?
Vector3 lookDir = _orientationProvider != null
    ? _orientationProvider.GetMovementForward()
    : GetCameraForward(); // Fallback auf Legacy

// Facing: Wie soll Character rotieren?
FacingMode facingMode = _facingProvider?.GetFacingMode()
    ?? FacingMode.MovementDirection;
Vector3 facingDir = _facingProvider?.GetFacingDirection()
    ?? Vector3.zero;

var input = new LocomotionInput
{
    MoveDirection = moveInput,
    LookDirection = lookDir,
    StepDetectionEnabled = /* ... bestehend ... */,
    SpeedModifier = /* ... bestehend ... */,
    DecelerationOverride = /* ... bestehend ... */,

    // NEU
    FacingMode = facingMode,
    FacingDirection = facingDir,
};
```

#### GetCameraForward() — Bleibt als Fallback

Die Methode bleibt bestehen für den Fall, dass kein IOrientationProvider vorhanden ist (Legacy-Kompatibilität, Tests ohne Camera).

### 2. CharacterLocomotion.cs

**Pfad:** `Packages/Wiesenwischer.GameKit.CharacterController.Core/Runtime/Core/Locomotion/CharacterLocomotion.cs`

#### UpdateRotation() erweitern

**Vorher:**
```csharp
public void UpdateRotation(ref Quaternion currentRotation, float deltaTime)
{
    // SteerMode: Character alignt sich sofort zur LookDirection
    if (_currentInput.LookDirection != Vector3.zero
        && _config.SteerAlignCharacter
        && /* isSteerMode check */)
    {
        // Sofort zur LookDirection rotieren
    }

    // Normal: Rotiere in Bewegungsrichtung
    if (_config.RotateTowardsMovement && _lastComputedHorizontal.sqrMagnitude > 0.01f)
    {
        // Rotation zu Movement
    }
}
```

**Nachher:**
```csharp
public void UpdateRotation(ref Quaternion currentRotation, float deltaTime)
{
    switch (_currentInput.FacingMode)
    {
        case FacingMode.MovementDirection:
            RotateTowardsMovement(ref currentRotation, deltaTime);
            break;

        case FacingMode.CameraForward:
            RotateTowardsDirection(_currentInput.FacingDirection,
                                  ref currentRotation, deltaTime);
            break;

        case FacingMode.TargetLockOn:
            RotateTowardsDirection(_currentInput.FacingDirection,
                                  ref currentRotation, deltaTime);
            break;

        case FacingMode.None:
            // Keine Rotation
            break;
    }
}

private void RotateTowardsMovement(ref Quaternion currentRotation, float deltaTime)
{
    // Bestehendes Verhalten extrahiert:
    if (_config.RotateTowardsMovement &&
        _lastComputedHorizontal.sqrMagnitude > 0.01f)
    {
        Vector3 dir = _lastComputedHorizontal.normalized;
        _targetYaw = Mathf.Atan2(dir.x, dir.z) * Mathf.Rad2Deg;
        _currentYaw = Mathf.MoveTowardsAngle(
            _currentYaw, _targetYaw, _config.RotationSpeed * deltaTime);
        currentRotation = Quaternion.Euler(0, _currentYaw, 0);
    }
}

private void RotateTowardsDirection(Vector3 direction,
                                     ref Quaternion currentRotation,
                                     float deltaTime)
{
    if (direction.sqrMagnitude < 0.001f) return;

    Vector3 flat = new Vector3(direction.x, 0, direction.z).normalized;
    _targetYaw = Mathf.Atan2(flat.x, flat.z) * Mathf.Rad2Deg;
    _currentYaw = Mathf.MoveTowardsAngle(
        _currentYaw, _targetYaw, _config.RotationSpeed * deltaTime);
    currentRotation = Quaternion.Euler(0, _currentYaw, 0);
}
```

#### Bestehende SteerAlignCharacter-Logik entfernen

Die bisherige `SteerAlignCharacter`-Prüfung in `UpdateRotation()` wird durch den `FacingMode.CameraForward` Case ersetzt. Die Config-Property `SteerAlignCharacter` kann bestehen bleiben (für eventuelle Zukunftsnutzung), aber die direkte Abfrage in UpdateRotation wird entfernt.

## Anweisungen

### Schritt 1: PlayerController — Provider-Felder + Auflösung

1. Füge `_orientationProvider` und `_facingProvider` Felder hinzu
2. In `Start()` oder dort wo `ResolveOrbitProvider()` aufgerufen wird: Auch die neuen Provider auflösen
3. Robuste Auflösung mit Fallback auf Legacy-Verhalten

### Schritt 2: PlayerController — ApplyMovement() anpassen

1. `LookDirection` von `IOrientationProvider.GetMovementForward()` lesen (statt `isSteerMode ? GetCameraForward() : transform.forward`)
2. `FacingMode` und `FacingDirection` von `IFacingProvider` lesen
3. Neue Felder in `LocomotionInput` setzen
4. Fallback-Logik für fehlende Provider beibehalten

### Schritt 3: CharacterLocomotion — UpdateRotation() refactoren

1. Bestehende Rotation-Logik in `RotateTowardsMovement()` extrahieren
2. Neue Methode `RotateTowardsDirection()` erstellen
3. Switch auf `_currentInput.FacingMode` als Dispatcher
4. Alte `SteerAlignCharacter`-Branch entfernen (durch FacingMode ersetzt)

### Schritt 4: Manuelle Verifikation

1. ActionCombat Preset: W = Camera-Vorwärts (wie bisher)
2. ClassicMMO ohne Button: W = Character-Vorwärts (NEU — war vorher nicht möglich)
3. ClassicMMO mit RMB: W = Camera-Vorwärts + Character rotiert zur Kamera (wie SteerOrbit)
