# 29.5 CameraInputSettings & Sensitivität

> **Commit:** `feat(phase-29): 29.5 CameraInputSettings & Sensitivität`
> **Branch:** `feat/camera-input-settings` (vom Integration-Branch)

---

## Ziel

**Runtime-konfigurierbare Kamera-Sensitivität** über ein ScriptableObject. Maus X/Y Sensitivität, InvertY, Scroll-Sensitivität und FOV-basiertes Scaling. Settings können über UI-Slider zur Runtime modifiziert werden.

---

## Neue Dateien

### CameraInputSettings.cs

**Pfad:** `Packages/Wiesenwischer.GameKit.Camera.Core/Runtime/Input/CameraInputSettings.cs`

```csharp
using UnityEngine;

namespace Wiesenwischer.GameKit.Camera
{
    /// <summary>
    /// Runtime-konfigurierbare Input-Settings für die Kamera.
    /// Als ScriptableObject: Änderungen über UI-Slider wirken sofort.
    /// </summary>
    [CreateAssetMenu(menuName = "GameKit/Camera/Input Settings")]
    public class CameraInputSettings : ScriptableObject
    {
        [Header("Mouse Sensitivity")]
        [Range(0.1f, 10f)]
        [Tooltip("Horizontale Maus-Sensitivität")]
        public float MouseSensitivityX = 1f;

        [Range(0.1f, 10f)]
        [Tooltip("Vertikale Maus-Sensitivität")]
        public float MouseSensitivityY = 1f;

        [Header("Gamepad Sensitivity")]
        [Range(0.1f, 10f)]
        [Tooltip("Horizontale Gamepad-Stick-Sensitivität")]
        public float GamepadSensitivityX = 1f;

        [Range(0.1f, 10f)]
        [Tooltip("Vertikale Gamepad-Stick-Sensitivität")]
        public float GamepadSensitivityY = 1f;

        [Header("Scroll")]
        [Range(0.1f, 5f)]
        [Tooltip("Zoom-Scroll-Sensitivität")]
        public float ScrollSensitivity = 1f;

        [Header("Inversion")]
        [Tooltip("Y-Achse invertieren")]
        public bool InvertY;

        [Header("FOV-Based Scaling")]
        [Tooltip("Referenz-FOV für Sensitivity-Skalierung (Grad)")]
        public float BaseFov = 60f;

        [Tooltip("Sensitivity automatisch mit FOV skalieren")]
        public bool EnableFovScaling = true;
    }
}
```

## Bestehende Datei modifizieren

### CameraInputPipeline.cs — Settings integrieren

**Pfad:** `Packages/Wiesenwischer.GameKit.Camera.Core/Runtime/Input/CameraInputPipeline.cs`

#### Neues Feld

```csharp
[SerializeField] private CameraInputSettings _inputSettings;
```

#### Sensitivity-Anwendung in ProcessInput()

Nach dem Lesen des Raw-Inputs, vor Deadzone/Acceleration:

```csharp
// Sensitivity anwenden
if (_inputSettings != null)
{
    if (_isGamepad)
    {
        rawLook.x *= _inputSettings.GamepadSensitivityX;
        rawLook.y *= _inputSettings.GamepadSensitivityY;
    }
    else
    {
        rawLook.x *= _inputSettings.MouseSensitivityX;
        rawLook.y *= _inputSettings.MouseSensitivityY;
    }

    // InvertY
    if (_inputSettings.InvertY)
        rawLook.y *= -1f;

    // FOV-Based Scaling
    if (_inputSettings.EnableFovScaling && _currentFov > 0f)
    {
        float fovScale = Mathf.Tan(_currentFov * 0.5f * Mathf.Deg2Rad)
                       / Mathf.Tan(_inputSettings.BaseFov * 0.5f * Mathf.Deg2Rad);
        rawLook *= fovScale;
    }
}
```

#### FOV-Zugang

Die Pipeline braucht den aktuellen FOV-Wert für FOV-Scaling. Optionen:

**Option A (empfohlen):** FOV aus CameraState lesen (wird vom CameraBrain vor ProcessInput gesetzt):
```csharp
private float _currentFov = 60f;

/// <summary>Aktuellen FOV für Sensitivity-Scaling setzen.</summary>
public void SetCurrentFov(float fov) => _currentFov = fov;
```

CameraBrain ruft `_inputPipeline.SetCurrentFov(State.Fov)` vor `ProcessInput()` auf.

#### Scroll-Sensitivität

```csharp
float rawScroll = _scrollAction?.ReadValue<float>() ?? 0f;
if (_inputSettings != null)
    rawScroll *= _inputSettings.ScrollSensitivity;
```

## Asset erstellen

### Default CameraInputSettings Asset

**Pfad:** `Assets/Config/CameraInputSettings.asset`

Erstelle ein Default-Asset über Unity's Create-Menü oder als SerializedObject mit den Default-Werten:
- MouseSensitivityX/Y: 1.0
- GamepadSensitivityX/Y: 1.0
- ScrollSensitivity: 1.0
- InvertY: false
- BaseFov: 60
- EnableFovScaling: true

**Hinweis:** Das Asset wird im Prefab am CameraInputPipeline-Serialized-Field referenziert.

## Anweisungen

### Schritt 1: CameraInputSettings.cs erstellen

1. Erstelle ScriptableObject im `Input/`-Ordner
2. `[CreateAssetMenu]` für einfache Erstellung
3. Alle Felder mit `[Range]` und `[Tooltip]` versehen

### Schritt 2: CameraInputPipeline.cs erweitern

1. `[SerializeField] CameraInputSettings _inputSettings` hinzufügen
2. Sensitivity-Multiplikation nach Raw-Input-Lesen
3. InvertY nach Sensitivity
4. FOV-Scaling nach InvertY
5. Scroll-Sensitivity
6. `SetCurrentFov()` Methode hinzufügen
7. Null-Check für `_inputSettings` (optional → kein Scaling wenn kein SO zugewiesen)

### Schritt 3: CameraBrain — FOV an Pipeline übergeben

1. In `LateUpdate()`, vor `_inputPipeline.ProcessInput()`:
   ```csharp
   _inputPipeline.SetCurrentFov(State.Fov);
   ```

### Schritt 4: Default Asset erstellen

1. Erstelle `Assets/Config/CameraInputSettings.asset` (ScriptableObject)
2. Default-Werte belassen
