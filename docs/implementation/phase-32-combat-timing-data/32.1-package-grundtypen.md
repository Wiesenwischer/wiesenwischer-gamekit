---

## Anweisungen

### 1. Package-Verzeichnis erstellen

```
Packages/Wiesenwischer.GameKit.Combat.Core/
├── package.json
├── Runtime/
│   ├── Wiesenwischer.GameKit.Combat.Core.Runtime.asmdef
│   ├── Data/
│   └── Core/
├── Tests/
│   └── Runtime/
│       ├── Wiesenwischer.GameKit.Combat.Core.Tests.Runtime.asmdef
│       └── Core/
└── Editor/
```

### 2. package.json

```json
{
  "name": "com.wiesenwischer.gamekit.combat.core",
  "version": "0.1.0",
  "displayName": "Wiesenwischer GameKit - Combat Core",
  "description": "Data-driven Combat Timing System mit Frame-basiertem Hit Detection. Grundlage für Combat Animation Tuning Tool und Combat Abilities.",
  "unity": "2022.3",
  "dependencies": {}
}
```

**Keine Abhängigkeiten** — Combat.Core ist ein eigenständiges Datenmodell-Package.

### 5. Grundtypen (Platzhalter)

Erstelle leere Namespace-Dateien als Platzhalter:

**`Runtime/Data/.gitkeep`** (oder leere Klasse)
**`Runtime/Core/.gitkeep`** (oder leere Klasse)
