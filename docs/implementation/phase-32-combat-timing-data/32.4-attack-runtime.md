## Anweisungen

### 1. FrameCalculator erstellen

**Datei:** `Runtime/Core/FrameCalculator.cs`

Reine statische Utility-Klasse für Frame-Berechnungen. Kein State, kein MonoBehaviour.

```csharp
using UnityEngine;

namespace Wiesenwischer.GameKit.Combat
{
    /// <summary>
    /// Statische Utility für deterministische Frame-Berechnungen.
    /// Berechnet den aktuellen Frame einer Attack basierend auf
    /// Startzeit und Animationslänge.
    ///
    /// Gameplay Anchor: attackStartTime = Time.time
    /// Dieser Zeitpunkt ist deterministisch, netzwerkfreundlich und tool-unabhängig.
    /// </summary>
    public static class FrameCalculator
    {
        /// <summary>
        /// Berechnet den aktuellen Frame einer laufenden Attack.
        /// </summary>
        /// <param name="attackStartTime">Zeitpunkt an dem die Attack gestartet wurde.</param>
        /// <param name="currentTime">Aktuelle Zeit (normalerweise Time.time).</param>
        /// <param name="animationLength">Länge der Animation in Sekunden.</param>
        /// <param name="totalFrames">Gesamtzahl der Frames der Attack.</param>
        /// <returns>Aktueller Frame (0-basiert, geclamped auf 0..totalFrames-1).</returns>
        public static int CalculateCurrentFrame(
            float attackStartTime,
            float currentTime,
            float animationLength,
            int totalFrames)
        {
            if (animationLength <= 0f || totalFrames <= 0)
                return 0;

            float elapsed = currentTime - attackStartTime;
            float normalizedTime = Mathf.Clamp01(elapsed / animationLength);

            return Mathf.Clamp(
                Mathf.FloorToInt(normalizedTime * totalFrames),
                0,
                totalFrames - 1);
        }

        /// <summary>
        /// Berechnet den aktuellen Frame aus der normalisierten Animation-Zeit.
        /// Nützlich wenn die normalizedTime direkt vom Animator kommt.
        /// </summary>
        /// <param name="normalizedTime">Normalisierte Zeit (0..1) der Animation.</param>
        /// <param name="totalFrames">Gesamtzahl der Frames der Attack.</param>
        /// <returns>Aktueller Frame (0-basiert).</returns>
        public static int FrameFromNormalizedTime(float normalizedTime, int totalFrames)
        {
            if (totalFrames <= 0)
                return 0;

            float clamped = Mathf.Clamp01(normalizedTime % 1f);
            return Mathf.Clamp(
                Mathf.FloorToInt(clamped * totalFrames),
                0,
                totalFrames - 1);
        }

        /// <summary>
        /// Konvertiert einen Frame-Index in normalisierte Zeit (0..1).
        /// Nützlich für Animation Scrubbing im Tool.
        /// </summary>
        public static float NormalizedTimeFromFrame(int frame, int totalFrames)
        {
            if (totalFrames <= 0)
                return 0f;

            return Mathf.Clamp01((float)frame / totalFrames);
        }

        /// <summary>
        /// Prüft ob der aktuelle Frame in einem HitWindow liegt.
        /// </summary>
        public static bool IsInHitWindow(int currentFrame, HitWindow window)
        {
            return window.ContainsFrame(currentFrame);
        }
    }
}
```

### 2. AttackRuntime erstellen

**Datei:** `Runtime/Core/AttackRuntime.cs`

MonoBehaviour das aktive Attacks trackt und Frame-Events bereitstellt.

```csharp
using System;
using UnityEngine;

namespace Wiesenwischer.GameKit.Combat
{
    /// <summary>
    /// Trackt eine laufende Attack zur Laufzeit.
    /// Berechnet pro Frame den aktuellen Attack-Frame
    /// und ermittelt ob Hit Windows aktiv sind.
    ///
    /// Verwendung:
    /// 1. StartAttack(definition, animLength) aufrufen
    /// 2. Tick(currentTime) jeden Frame aufrufen
    /// 3. Events (OnHitWindowEnter/Exit) reagieren auf Timing-Änderungen
    /// </summary>
    public class AttackRuntime
    {
        private AttackDefinition _activeAttack;
        private float _attackStartTime;
        private float _animationLength;
        private int _currentFrame;
        private bool _isHitWindowActive;
        private bool _isActive;

        /// <summary>Ob aktuell eine Attack läuft.</summary>
        public bool IsActive => _isActive;

        /// <summary>Aktuelle AttackDefinition (null wenn keine Attack aktiv).</summary>
        public AttackDefinition ActiveAttack => _activeAttack;

        /// <summary>Aktueller Frame der laufenden Attack.</summary>
        public int CurrentFrame => _currentFrame;

        /// <summary>Ob das primäre Hit Window gerade aktiv ist.</summary>
        public bool IsHitWindowActive => _isHitWindowActive;

        /// <summary>Normalisierte Zeit (0..1) der aktuellen Attack.</summary>
        public float NormalizedTime =>
            _activeAttack != null
                ? FrameCalculator.NormalizedTimeFromFrame(_currentFrame, _activeAttack.totalFrames)
                : 0f;

        // --- Events ---

        /// <summary>Feuert wenn das Hit Window betreten wird.</summary>
        public event Action<AttackDefinition> OnHitWindowEnter;

        /// <summary>Feuert wenn das Hit Window verlassen wird.</summary>
        public event Action<AttackDefinition> OnHitWindowExit;

        /// <summary>Feuert wenn die Attack abgeschlossen ist (letzter Frame erreicht).</summary>
        public event Action<AttackDefinition> OnAttackComplete;

        /// <summary>
        /// Startet eine neue Attack.
        /// </summary>
        /// <param name="attack">Die AttackDefinition.</param>
        /// <param name="animationLength">Länge der zugehörigen Animation in Sekunden.</param>
        /// <param name="startTime">Startzeitpunkt (normalerweise Time.time).</param>
        public void StartAttack(AttackDefinition attack, float animationLength, float startTime)
        {
            _activeAttack = attack;
            _animationLength = animationLength;
            _attackStartTime = startTime;
            _currentFrame = 0;
            _isHitWindowActive = false;
            _isActive = true;
        }

        /// <summary>
        /// Aktualisiert den Attack-State. Jeden Frame aufrufen.
        /// </summary>
        /// <param name="currentTime">Aktuelle Zeit (normalerweise Time.time).</param>
        public void Tick(float currentTime)
        {
            if (!_isActive || _activeAttack == null)
                return;

            // Frame berechnen
            int previousFrame = _currentFrame;
            _currentFrame = FrameCalculator.CalculateCurrentFrame(
                _attackStartTime, currentTime, _animationLength, _activeAttack.totalFrames);

            // Hit Window Transitions
            bool inWindow = FrameCalculator.IsInHitWindow(
                _currentFrame, _activeAttack.primaryHitWindow);

            if (inWindow && !_isHitWindowActive)
            {
                _isHitWindowActive = true;
                OnHitWindowEnter?.Invoke(_activeAttack);
            }
            else if (!inWindow && _isHitWindowActive)
            {
                _isHitWindowActive = false;
                OnHitWindowExit?.Invoke(_activeAttack);
            }

            // Attack abgeschlossen?
            if (_currentFrame >= _activeAttack.totalFrames - 1)
            {
                var completedAttack = _activeAttack;
                Stop();
                OnAttackComplete?.Invoke(completedAttack);
            }
        }

        /// <summary>Bricht die aktuelle Attack ab.</summary>
        public void Stop()
        {
            if (_isHitWindowActive)
            {
                _isHitWindowActive = false;
                OnHitWindowExit?.Invoke(_activeAttack);
            }

            _isActive = false;
            _activeAttack = null;
            _currentFrame = 0;
        }
    }
}
```

**Design-Entscheidungen:**

- **Kein MonoBehaviour:** `AttackRuntime` ist eine reine C#-Klasse (POCO). Der Caller (z.B. CombatController oder AbilitySystem) ruft `Tick()` auf. Das macht es testbar und netzwerkfreundlich.
- **Events statt Callbacks:** `OnHitWindowEnter`/`OnHitWindowExit` für lose Kopplung.
- **Einzelne aktive Attack:** Einfaches Modell — eine Attack zur Zeit. Erweiterbar auf Queuing/Combo in Phase 9.
