## Anweisungen

### 1. IHitboxController Interface

**Datei:** `Runtime/Core/IHitboxController.cs`

```csharp
namespace Wiesenwischer.GameKit.Combat
{
    /// <summary>
    /// Interface für Hitbox-Steuerung.
    /// Implementierungen aktivieren/deaktivieren Collider basierend auf Frame-Timing.
    /// Ermöglicht verschiedene Hitbox-Strategien (Collider, Raycast, Overlap etc.).
    /// </summary>
    public interface IHitboxController
    {
        /// <summary>Aktiviert die Hitbox für die gegebene Attack.</summary>
        void EnableHitbox(AttackDefinition attack);

        /// <summary>Deaktiviert die Hitbox.</summary>
        void DisableHitbox();

        /// <summary>Ob die Hitbox aktuell aktiv ist.</summary>
        bool IsActive { get; }
    }
}
```

### 2. CombatHitDetector erstellen

**Datei:** `Runtime/Core/CombatHitDetector.cs`

Verbindet `AttackRuntime` Events mit `IHitboxController`.

```csharp
using System;

namespace Wiesenwischer.GameKit.Combat
{
    /// <summary>
    /// Verbindet AttackRuntime mit IHitboxController.
    /// Aktiviert/deaktiviert Hitboxen automatisch basierend auf
    /// Hit Window Enter/Exit Events.
    ///
    /// Optionaler Damage-Callback wenn ein Hit registriert wird.
    /// Die konkrete Hit-Auswertung (Collision, Overlap etc.)
    /// liegt beim IHitboxController.
    /// </summary>
    public class CombatHitDetector : IDisposable
    {
        private readonly AttackRuntime _runtime;
        private readonly IHitboxController _hitbox;
        private bool _disposed;

        /// <summary>Feuert wenn die Hitbox aktiviert wird (mit AttackDefinition).</summary>
        public event Action<AttackDefinition> OnHitboxActivated;

        /// <summary>Feuert wenn die Hitbox deaktiviert wird.</summary>
        public event Action OnHitboxDeactivated;

        public CombatHitDetector(AttackRuntime runtime, IHitboxController hitbox)
        {
            _runtime = runtime;
            _hitbox = hitbox;

            _runtime.OnHitWindowEnter += HandleHitWindowEnter;
            _runtime.OnHitWindowExit += HandleHitWindowExit;
            _runtime.OnAttackComplete += HandleAttackComplete;
        }

        private void HandleHitWindowEnter(AttackDefinition attack)
        {
            _hitbox.EnableHitbox(attack);
            OnHitboxActivated?.Invoke(attack);
        }

        private void HandleHitWindowExit(AttackDefinition attack)
        {
            _hitbox.DisableHitbox();
            OnHitboxDeactivated?.Invoke();
        }

        private void HandleAttackComplete(AttackDefinition attack)
        {
            if (_hitbox.IsActive)
            {
                _hitbox.DisableHitbox();
                OnHitboxDeactivated?.Invoke();
            }
        }

        public void Dispose()
        {
            if (_disposed) return;
            _disposed = true;

            _runtime.OnHitWindowEnter -= HandleHitWindowEnter;
            _runtime.OnHitWindowExit -= HandleHitWindowExit;
            _runtime.OnAttackComplete -= HandleAttackComplete;

            if (_hitbox.IsActive)
                _hitbox.DisableHitbox();
        }
    }
}
```

**Design-Entscheidungen:**

- **IHitboxController ist ein Interface:** Konkrete Implementierungen (Collider-basiert, Raycast, Overlap-Sphere) werden in Phase 9 oder Game-Code bereitgestellt. Phase 32 definiert nur den Vertrag.
- **CombatHitDetector als Brücke:** Lose Kopplung zwischen Timing (AttackRuntime) und physischer Hit Detection (IHitboxController). Event-basiert, testbar.
- **IDisposable:** Sauberes Aufräumen der Event-Subscriptions.
