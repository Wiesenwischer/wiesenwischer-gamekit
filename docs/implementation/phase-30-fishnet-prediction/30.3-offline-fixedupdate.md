## Ziel

Den custom `TickSystem` Accumulator durch Unity's nativen `FixedUpdate()` ersetzen fuer den Offline-Modus. Dies vereinfacht den Code erheblich und stellt sicher, dass Offline und Online den gleichen `SimulateTick()` Entry-Point nutzen.

---

## Anweisungen

### 1. TickSystem-Nutzung in PlayerController entfernen

In `PlayerController.cs`:

```csharp
// ENTFERNEN:
private TickSystem _tickSystem;

// ENTFERNEN:
private void InitializeTickSystem()
{
    _tickSystem = new TickSystem(/* ... */);
    _tickSystem.OnFixedTick += OnFixedTick;
}

// ENTFERNEN (falls vorhanden):
private void OnFixedTick()
{
    // ... alte Tick-Logik, jetzt in SimulateTick()
}
```

### 2. FixedUpdate() hinzufuegen

```csharp
private void FixedUpdate()
{
    // Nur simulieren wenn KEIN externer Driver aktiv ist
    if (_simulationDriver != null && _simulationDriver.IsActive)
        return;

    SimulateTick(Time.fixedDeltaTime);
}
```

**Warum `Time.fixedDeltaTime`?**
- Unity's `FixedUpdate()` laeuft in festen Intervallen (default 0.02s = 50Hz)
- `Time.fixedDeltaTime` ist innerhalb von `FixedUpdate()` identisch mit `Time.deltaTime`
- Explizit `fixedDeltaTime` zu nutzen macht die Intention klar

**Hinweis:** Unity's Default ist 50Hz (0.02s). Fuer 60Hz `Time.fixedDeltaTime = 1f/60f` in Project Settings setzen. Alternativ 50Hz akzeptieren — FishNet's TickRate ist separat konfigurierbar.

### 3. ConsumeMovementEvents() in SimulateTick() verlagern

Falls `ConsumeMovementEvents()` bisher in `Update()` aufgerufen wurde, muss es nach `SimulateTick()` verlagert werden:

```csharp
public void SimulateTick(float deltaTime)
{
    if (!_initialized) return;

    _movementStateMachine?.Update(deltaTime);
    ConsumeMovementEvents();
    AbilitySystem?.Tick(deltaTime);

    _currentTick++;
}
```

### 4. Update() vereinfachen

```csharp
private void Update()
{
    // Input wird immer in Update() gesammelt (Frame-Rate)
    UpdateInput();

    // TickSystem-Aufruf entfaellt komplett
    // FixedUpdate() oder externer Driver treibt SimulateTick()
}
```

### 5. CurrentTick Property vereinfachen

```csharp
// ALT (TickSystem-basiert):
public int CurrentTick => _tickSystem?.CurrentTick ?? 0;

// NEU (einfacher Counter):
private uint _currentTick;
public uint CurrentTick => _currentTick;
```

Der Counter wird in `SimulateTick()` inkrementiert. Im Netzwerk-Modus kann der `NetworkCharacterDriver` den Tick von `TimeManager.Tick` setzen.
