# 30.2 Deterministisches Timing — deltaTime durchreichen

**Commit:** `feat(phase-30): 30.2 Deterministisches Timing`
**Branch:** `feat/deterministic-timing`

---

## Ziel

Alle Simulation-Systeme bekommen `deltaTime` als Parameter statt `Time.deltaTime`/`Time.time` direkt zu lesen. Bei FishNet Reconcile-Replay wird `[Replicate]` mehrfach hintereinander aufgerufen — `Time.deltaTime`/`Time.time` sind waehrend Replay NICHT korrekt (Frame-Zeit statt Tick-Zeit). Dieser Schritt ist **der kritischste** der Phase, da er die meisten Dateien beruehrt.

---

## Anweisungen

### 1. IState Interface aendern

In `Packages/.../Core/StateMachine/IState.cs`:

```csharp
// ALT:
void Update();

// NEU:
void Update(float deltaTime);
```

**Effekt:** Der Compiler erzwingt jetzt die Signatur-Aenderung in ALLEN State-Implementierungen.

### 2. PlayerMovementStateMachine aendern

In `PlayerMovementStateMachine.cs`:

```csharp
// ALT:
public void Update()
{
    _currentState?.Update();
}

// NEU:
public void Update(float deltaTime)
{
    _currentState?.Update(deltaTime);
}
```

### 3. PlayerMovementState (Base Class) aendern

In `PlayerMovementState.cs` — diese Aenderung betrifft ALLE States:

```csharp
// ALT:
public void Update()
{
    stateTime += Time.deltaTime;
    OnUpdate();
}

protected virtual void OnUpdate() { }

// NEU:
public void Update(float deltaTime)
{
    stateTime += deltaTime;
    OnUpdate(deltaTime);
}

protected virtual void OnUpdate(float deltaTime) { }
```

### 4. State-Subklassen mit Time.deltaTime/Time.time Nutzung

**PlayerSlidingState.cs** (3 Stellen):

```csharp
// ALT:
_slideStartTime = Time.time;

// NEU:
// Entfaellt! stateTime startet bei 0 in OnEnter() und wird automatisch akkumuliert.
// _slideStartTime Feld komplett entfernen.

// ALT:
float slideDuration = Time.time - _slideStartTime;

// NEU:
float slideDuration = stateTime;  // stateTime IST die Dauer seit OnEnter()

// ALT:
rotation = Config.RotationSpeed * Time.deltaTime;

// NEU:
rotation = Config.RotationSpeed * deltaTime;
```

**PlayerGroundedState.cs:**

```csharp
// ALT:
ReusableData.TimeSinceGrounded += Time.deltaTime;

// NEU:
ReusableData.TimeSinceGrounded += deltaTime;
```

**PlayerMovingState.cs:**

```csharp
// ALT:
_noInputTimer += Time.deltaTime;

// NEU:
_noInputTimer += deltaTime;
```

**PlayerHardLandingState.cs:**

```csharp
// ALT:
_fallbackTimer -= Time.deltaTime;

// NEU:
_fallbackTimer -= deltaTime;
```

### 5. Alle anderen State-Subklassen — Signatur-Update

Jede State-Klasse die `OnUpdate()` ueberschreibt muss die Signatur anpassen:

```csharp
// ALT:
protected override void OnUpdate()

// NEU:
protected override void OnUpdate(float deltaTime)
```

**Betrifft (mindestens):**
- `PlayerIdlingState`
- `PlayerWalkingState`
- `PlayerRunningState`
- `PlayerSprintingState`
- `PlayerJumpingState`
- `PlayerFallingState`
- `PlayerLandingState`
- `PlayerSoftLandingState`
- `PlayerRollingState`
- `PlayerCrouchIdleState`
- `PlayerCrouchWalkingState`
- `PlayerStoppingState` (und Varianten)
- Alle weiteren `PlayerMovementState`-Subklassen

**Tipp:** Kompiliere nach der Base-Class-Aenderung — der Compiler zeigt ALLE Stellen die angepasst werden muessen.

### 6. CharacterLocomotion.cs — Treppen-Erkennung

Die Treppen-Erkennung nutzt `Time.time` fuer absolute Timestamps:

```csharp
// NEU: Feld hinzufuegen
private float _simulationTime;

// In BeforeCharacterUpdate(float deltaTime):
// ALT:
float now = Time.time;

// NEU:
_simulationTime += deltaTime;
float now = _simulationTime;

// ALT:
_lastStepTime = Time.time;

// NEU:
_lastStepTime = _simulationTime;

// ALT:
Time.time - _lastStepTime

// NEU:
_simulationTime - _lastStepTime
```

### 7. PlayerController.SimulateTick() — deltaTime weiterreichen

```csharp
public void SimulateTick(float deltaTime)
{
    if (!_initialized) return;

    _movementStateMachine?.Update(deltaTime);
    ConsumeMovementEvents();
    AbilitySystem?.Tick(deltaTime);  // war: Time.deltaTime

    _currentTick++;
}
```

### 8. NICHT aendern (Rendering-Layer)

Folgende Systeme lesen weiterhin `Time.deltaTime` — sie laufen in `Update()`/`LateUpdate()` und sind NICHT Teil der Simulation:

- `AnimatorParameterBridge` — Blend-Smoothing
- `ThirdPersonCamera` / `CameraBrain` — Kamera-Glaettung
- `LookAtIK` / `FootLock` — IK-Systeme
- `CameraPresetSwitcher` — Debug-Tool
- `GroundingSmoother` — Visuelles Y-Smoothing
