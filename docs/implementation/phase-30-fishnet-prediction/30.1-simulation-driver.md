## Ziel

Driver-Abstraktion in Core erstellen, damit die Simulation sowohl online (FishNet `TimeManager.OnTick`) als auch offline (`FixedUpdate`) getrieben werden kann. Dazu die bestehende `OnFixedTick()`-Logik in eine aufrufbare `SimulateTick(float deltaTime)` Methode extrahieren.

---

## Anweisungen

### 1. ISimulationDriver Interface erstellen

Neue Datei: `Packages/Wiesenwischer.GameKit.CharacterController.Core/Runtime/Core/Network/ISimulationDriver.cs`

```csharp
namespace Wiesenwischer.GameKit.CharacterController.Core
{
    /// <summary>
    /// Abstraktion fuer den Simulation-Treiber.
    /// Online: NetworkCharacterDriver (FishNet TickNetworkBehaviour)
    /// Offline: PlayerController.FixedUpdate()
    /// </summary>
    public interface ISimulationDriver
    {
        /// <summary>
        /// True wenn ein externer Driver die Simulation treibt.
        /// Wenn true, darf PlayerController NICHT selbst simulieren.
        /// </summary>
        bool IsActive { get; }

        /// <summary>
        /// Delta-Zeit pro Tick (z.B. TimeManager.TickDelta).
        /// </summary>
        float TickDelta { get; }

        /// <summary>
        /// Aktueller Tick-Zaehler (z.B. TimeManager.Tick).
        /// </summary>
        uint CurrentTick { get; }
    }
}
```

**Wichtig:** Dieses Interface lebt in `CharacterController.Core` — KEIN FishNet-Import!

### 2. SimulateTick() in PlayerController extrahieren

In `PlayerController.cs`:

1. **Neue public Methode `SimulateTick(float deltaTime)`** erstellen:
   - Inhalt aus der bestehenden `OnFixedTick()` / Tick-Logik extrahieren
   - StateMachine Update aufrufen
   - `ConsumeMovementEvents()` aufrufen
   - Bewegung anwenden
   - AbilitySystem Tick aufrufen
   - Tick-Counter inkrementieren

```csharp
/// <summary>
/// Fuehrt einen Simulations-Tick aus.
/// Wird von ISimulationDriver (online) oder FixedUpdate (offline) aufgerufen.
/// </summary>
public void SimulateTick(float deltaTime)
{
    if (!_initialized) return;

    // 1. StateMachine updaten
    _movementStateMachine?.Update();

    // 2. Movement Events konsumieren (Jump, etc.)
    ConsumeMovementEvents();

    // 3. AbilitySystem tick
    AbilitySystem?.Tick(Time.deltaTime);  // HINWEIS: wird in 30.2 auf deltaTime umgestellt

    // 4. Tick-Counter
    _currentTick++;
}
```

### 3. ISimulationDriver Referenz in PlayerController

```csharp
private ISimulationDriver _simulationDriver;

private void InitializeSystems()
{
    // ... bestehende Initialisierung ...

    // SimulationDriver suchen (optional, nur im Netzwerk-Modus vorhanden)
    _simulationDriver = GetComponent<ISimulationDriver>();
}

/// <summary>
/// Externer Zugriff auf den SimulationDriver (fuer NetworkCharacterDriver).
/// </summary>
public ISimulationDriver SimulationDriver => _simulationDriver;
```

### 4. Update() anpassen

In der bestehenden `Update()` Methode:
- `_tickSystem.Update()` NUR aufrufen wenn kein externer Driver aktiv ist

```csharp
private void Update()
{
    // Input sammeln (immer, auch mit externem Driver)
    UpdateInput();

    // TickSystem nur wenn kein externer Driver
    if (_simulationDriver == null || !_simulationDriver.IsActive)
    {
        _tickSystem?.Update();
    }
}
```

**Hinweis:** `_tickSystem` wird erst in Schritt 30.3 komplett entfernt. In 30.1 wird nur sichergestellt, dass es nicht laeuft wenn ein externer Driver aktiv ist.
