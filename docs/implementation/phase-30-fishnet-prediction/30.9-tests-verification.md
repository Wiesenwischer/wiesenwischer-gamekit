### 2. Unit Tests: ISimulationDriver Interface

**Datei:** `Core/Tests/Runtime/ISimulationDriverTests.cs`

```csharp
[TestFixture]
public class ISimulationDriverTests
{
    private class MockDriver : ISimulationDriver
    {
        public bool IsActive { get; set; }
        public float TickDelta { get; set; }
        public uint CurrentTick { get; set; }
    }

    [Test]
    public void MockDriver_ImplementsInterface()
    {
        var driver = new MockDriver
        {
            IsActive = true,
            TickDelta = 1f / 60f,
            CurrentTick = 42
        };

        Assert.IsTrue(driver.IsActive);
        Assert.AreEqual(1f / 60f, driver.TickDelta, 0.0001f);
        Assert.AreEqual(42u, driver.CurrentTick);
    }

    [Test]
    public void InactiveDriver_AllowsOfflineSimulation()
    {
        var driver = new MockDriver { IsActive = false };
        Assert.IsFalse(driver.IsActive);
    }
}
```

### 5. Play Mode Verifikation (manuell)

#### 5.1 Offline-Modus
- [ ] Spiel starten ohne Netzwerk → Character bewegt sich normal
- [ ] FixedUpdate treibt Simulation (Debug.Log in SimulateTick pruefen)
- [ ] Jump, Sprint, Crouch, Walk Toggle funktionieren
- [ ] Slope Sliding, Landing Roll funktionieren
- [ ] Kamera folgt smooth (keine Jitter)

#### 5.2 Online-Modus: Host
- [ ] Host starten → lokaler Spieler bewegt sich fluessig
- [ ] Kein Teleport/Jitter bei normaler Bewegung
- [ ] Jump funktioniert (One-Shot Input Handling)
- [ ] Sprint, Crouch, Walk Toggle funktionieren
- [ ] Kamera-Steuerung normal (keine Einschraenkungen)

#### 5.3 Online-Modus: Client verbinden
- [ ] Zweiter Client verbindet sich (ParrelSync)
- [ ] Beide Spieler sehen sich
- [ ] Bewegung ist synchron (Client-Side Prediction laeuft)
- [ ] CameraYaw korrekt uebertragen (Bewegungsrichtung stimmt!)
- [ ] Animation-Sync funktioniert (Walk, Run, Jump sichtbar)

#### 5.4 Reconciliation
- [ ] Kein staendiger Teleport-Jitter (PredictionBuffer-Bug aus Phase 6 behoben)
- [ ] Gelegentliche Korrekturen sind akzeptabel (Debug.Log: "Reconcile" selten, nicht jeden Tick)

#### 5.5 Visual Interpolation
- [ ] Bewegung ist smooth, kein Tick-Snapping sichtbar
- [ ] Kamera folgt interpoliertem Visual (nicht roher Simulation)
