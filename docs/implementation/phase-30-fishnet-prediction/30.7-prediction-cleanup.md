# 30.7 Alten Prediction-Code aufraeumen

**Commit:** `refactor(phase-30): 30.7 Alten Prediction-Code aufraeumen`
**Branch:** `refactor/prediction-cleanup`

---

## Ziel

Den durch FishNet Native Prediction ersetzten custom CSP-Code entfernen oder als obsolete markieren. Haelt das Projekt sauber und verhindert Verwirrung ueber aktive vs. inaktive Systeme.

---

## Anweisungen

### 1. Dateien ENTFERNEN (ersetzt durch FishNet native)

Diese Dateien sind vollstaendig durch `NetworkCharacterDriver` + FishNet `[Replicate]`/`[Reconcile]` ersetzt:

| Datei | Pfad | Ersetzt durch |
|-------|------|---------------|
| `NetworkInputSync.cs` | `Network.FishNet/Runtime/Core/` | `[Replicate]` in NetworkCharacterDriver |
| `NetworkStateSync.cs` | `Network.FishNet/Runtime/Core/` | `[Reconcile]` in NetworkCharacterDriver |
| `RemotePlayerInterpolator.cs` | `Network.FishNet/Runtime/Core/` | FishNet Spectator Prediction |
| `ControllerInputSerializer.cs` | `Network.FishNet/Runtime/Core/` | FishNet auto-serialisiert IReplicateData |
| `PredictionStateSerializer.cs` | `Network.FishNet/Runtime/Core/` | FishNet auto-serialisiert IReconcileData |

**Vorgehen:**
```bash
git rm Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/NetworkInputSync.cs
git rm Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/NetworkStateSync.cs
git rm Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/RemotePlayerInterpolator.cs
git rm Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/ControllerInputSerializer.cs
git rm Packages/Wiesenwischer.GameKit.Network.FishNet/Runtime/Core/PredictionStateSerializer.cs
```

**Auch die zugehoerigen .meta Dateien werden durch `git rm` automatisch entfernt.**

### 2. Dateien als `[Obsolete]` markieren (spaeter entfernbar)

Diese Dateien sind nicht mehr aktiv genutzt, koennten aber fuer Referenz oder Tests noch nuetzlich sein:

| Datei | Pfad | Grund |
|-------|------|-------|
| `TickSystem.cs` | `Core/Runtime/Core/Prediction/` | Ersetzt durch FixedUpdate (offline) / TimeManager (online) |
| `InputBuffer.cs` | `Core/Runtime/Core/Prediction/` | Ersetzt durch FishNet-internen Input Buffer |
| `PredictionBuffer.cs` | `Core/Runtime/Core/Prediction/` | Ersetzt durch FishNet Reconcile |
| `ControllerInput.cs` | `Core/Runtime/Core/Prediction/` | Ersetzt durch MoveReplicateData |
| `IPredictionSystem.cs` | `Core/Runtime/Core/Prediction/` | Nicht mehr genutzt |

**Vorgehen:** Jede Klasse mit `[Obsolete]` Attribut versehen:

```csharp
[System.Obsolete("Ersetzt durch FishNet Native Prediction (Phase 30). Wird in einer zukuenftigen Phase entfernt.")]
public class TickSystem
{
    // ...
}
```

### 3. Referenzen bereinigen

Nach dem Entfernen/Markieren pruefen ob Compile-Errors entstehen:

- `NetworkPlayer.cs` — Referenzen auf `NetworkInputSync` / `NetworkStateSync` entfernen
- `GameNetworkManager.cs` — Falls Referenzen vorhanden, entfernen
- Test-Dateien — Falls Tests die entfernten Klassen referenzieren, anpassen oder entfernen

### 4. Player Prefab bereinigen

Vom Player-Prefab die alten Komponenten entfernen:
- `NetworkInputSync` Komponente entfernen
- `NetworkStateSync` Komponente entfernen
- `RemotePlayerInterpolator` Komponente entfernen

**Die neuen Komponenten (`NetworkCharacterDriver`) wurden bereits in Schritt 30.6 hinzugefuegt.**

### 5. ApplyNetworkInput() entfernen

Die in 30.6 als `[Obsolete]` markierte Methode kann jetzt komplett entfernt werden, da keine Aufrufer mehr existieren:

```csharp
// ENTFERNEN aus PlayerController.cs:
// [Obsolete] public void ApplyNetworkInput(...) { ... }
```
